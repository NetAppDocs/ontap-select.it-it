= Supporto ONTAP Select per le funzionalità ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ONTAP Select supporta la maggior parte delle funzionalità ONTAP . Molte delle funzionalità ONTAP vengono concesse in licenza automaticamente per ciascun nodo quando si implementa un cluster. Tuttavia, alcune funzionalità richiedono una licenza separata.


NOTE: Le funzionalità di ONTAP con dipendenze specifiche dell'hardware non sono generalmente supportate con ONTAP Select.



[[ontap-features-licensed-by-default]]
[[licensed-ontap-features]]
== Funzionalità ONTAP con licenza predefinita

Le seguenti funzionalità di ONTAP sono supportate con ONTAP Select e concesse in licenza per impostazione predefinita.

[cols="1,1,1"]
|===
| Caratteristica | Scopri | Note 


| Protezione autonoma contro i ransomware (ARP) | link:https://docs.netapp.com/us-en/ontap/anti-ransomware/index.html["ONTAP Autonomous Ransomware Protection"^] | ONTAP Select supporta solo gli aggiornamenti ARP manuali. 


| CIFS | link:https://docs.netapp.com/us-en/ontap/smb-admin/index.html["SMB ONTAP"^] |  


| Deduplica e compressione | link:https://docs.netapp.com/us-en/ontap-restapi/storage_volumes_endpoint_overview.html["Gestione dei volumi di storage"^] |  


| Gestione delle chiavi esterne utilizzando il Key Management Interoperability Protocol (KMIP) | link:https://docs.netapp.com/us-en/ontap/encryption-at-rest/configure-netapp-volume-encryption-concept.html["Abilitazione e configurazione della gestione delle chiavi esterne"^] |  


| FlexCache | link:https://docs.netapp.com/us-en/ontap/flexcache-writeback/flexcache-write-back-guidelines.html["Write-back di ONTAP FlexCache"^] | ONTAP Select supporta i volumi cache FlexCache con write-back. *Attenzione*: esistono limitazioni per il write-back di FlexCache con ONTAP Select. Per ulteriori informazioni, consulta link:concept_ots_overview.html#flexcache-write-back-with-ontap-select["FlexCache write-back con ONTAP Select"]. 


| FlexClone | link:https://docs.netapp.com/us-en/ontap/volumes/flexclone-efficient-copies-concept.html["volumi ONTAP FlexClone"^] |  


| ISCSI  a| 
* link:https://docs.netapp.com/us-en/ontap-restapi/protocols_san_iscsi_credentials_endpoint_overview.html["Gestione delle credenziali iSCSI"^]
* link:https://docs.netapp.com/us-en/ontap-restapi/protocols_san_iscsi_services_endpoint_overview.html["Gestione dei servizi iSCSI"^]

| NVMe su TCP | link:https://docs.netapp.com/us-en/ontap-restapi/protocols_nvme_services_endpoint_overview.html["Gestione dei servizi NVMe"^] |  


| Funzionalità di multi-tenancy ONTAP | link:https://docs.netapp.com/us-en/ontap/concepts/svm-use-cases-concept.html["Casi d'uso di ONTAP SVM"^] |

| Disaster recovery delle macchine virtuali storage (DR SVM) | link:https://docs.netapp.com/us-en/ontap/data-protection/snapmirror-svm-replication-concept.html["replica SVM di ONTAP SnapMirror"^] | ONTAP Select supporta SVM DR sia come sorgente che come destinazione, con un massimo di 16 relazioni. Il supporto SVM DR è limitato all'utilizzo della versione di ONTAP sorgente fino a versioni +2. Ad esempio, la sorgente ONTAP Select 9.16.1 può connettersi alle destinazioni ONTAP versioni 9.16.1, 9.17.1 o 9.18.1.

== Funzionalità ONTAP con licenza separata

Devi acquisire una licenza separata per le seguenti funzionalità di ONTAP supportate da ONTAP Select ma non incluse nella licenza predefinita.

[cols="1,1,1"]
|===
| Caratteristica | Scopri | Nota 


| FabricPool | link:https://docs.netapp.com/us-en/ontap/concepts/fabricpool-concept.html["ONTAP FabricPool"^] | Non è necessaria una licenza FabricPool quando si utilizza StorageGRID. 


| Scheda di sicurezza MetroCluster | link:reference_plan_ots_mcc_sds.html["MetroCluster SDS per ONTAP Select"] | Si tratta di un'offerta di licenza premium ONTAP Select. 


| SnapMirror cloud | link:https://docs.netapp.com/us-en/ontap/concepts/snapmirror-cloud-backups-object-store-concept.html["SnapMirror cloud backup su storage a oggetti"^] | È necessario link:https://mysupport.netapp.com/site/help["aprire una richiesta di assistenza non tecnica"^] per ottenere una licenza cloud SnapMirror. 
|===
