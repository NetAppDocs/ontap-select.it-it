= Proteggere un'implementazione ONTAP Select
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Puoi proteggere una distribuzione di ONTAP Select cambiando la password dell'account amministratore della macchina virtuale Deploy quando necessario usando l'interfaccia a riga di comando.

.Fasi
. Accedere alla CLI dell'utilità di implementazione utilizzando l'account amministratore.
. Modificare la password:
`password modify`
. Rispondere a tutte le richieste in base all'ambiente in uso.
